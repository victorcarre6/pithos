# Instructions — continuité

Le rapport durable est un contrat, pas un résumé décoratif.

- N'utilise pas `pi --continue` ou une session persistante pour démontrer la reprise.
- Publie `latest.md` par écriture temporaire puis renommage atomique.
- Préserve toujours le dernier rapport valide.
- Valide structure et métadonnées avant publication.
- Garde `Context` factuel, `Work` vérifiable et `Next items` actionnable.
- Teste les interruptions et fichiers invalides.
- N'introduis ni SQLite ni logique de dashboard dans ce projet.
